# zstack_l2vxlan_network_pool (Resource)

Manage a ZStack L2 VXLAN network pool.

## Example Usage

```terraform
# Copyright (c) ZStack.io, Inc.

resource "zstack_l2vxlan_network_pool" "example" {
  name         = "example-vxlan-pool"
  description  = "Example L2 VXLAN network pool"
  zone_uuid    = "a1b2c3d4e5f6789a0b1c2d3e4f5a6b7c"
  vswitch_type = "LinuxBridge"

  # Optional. Omit this attribute to let ZStack discover the host interface
  # from the VTEP CIDR when the pool is attached to a cluster.
  # physical_interface = "bond0"
}

output "l2vxlan_network_pool" {
  value = zstack_l2vxlan_network_pool.example
}
```

## Physical Interface Selection

`physical_interface` is optional. When omitted, ZStack discovers the host interface from the VTEP CIDR when the pool is attached to a cluster. Set it explicitly, for example to `bond0` or `zsn0`, only when the VXLAN pool must use a fixed interface. Changing an explicitly configured interface recreates the pool.

## Schema

### Required

- `name` (String) The name of the L2 VXLAN network pool.
- `zone_uuid` (String) The UUID of the zone where the VXLAN pool is created.

### Optional

- `description` (String) The description of the L2 VXLAN network pool.
- `isolated` (Boolean) Whether the VXLAN pool is isolated.
- `physical_interface` (String) The physical network interface used by the VXLAN pool, for example `bond0`. Omit it to let ZStack select the interface from the VTEP CIDR when the pool is attached.
- `pvlan` (String) The private VLAN setting for the pool.
- `resource_uuid` (String) A custom UUID requested when creating the VXLAN pool.
- `system_tags` (List of String) System tags sent while creating the VXLAN pool.
- `tag_uuids` (List of String) Tag UUIDs attached while creating the VXLAN pool.
- `type` (String) The L2 network type reported by ZStack.
- `vswitch_type` (String) The virtual switch type, such as `LinuxBridge` or `OvsDpdk`.

### Read-Only

- `attached_cluster_uuids` (List of String) Cluster UUIDs currently attached to the VXLAN pool.
- `uuid` (String) The UUID of the L2 VXLAN network pool.
- `virtual_network_id` (Number) The virtual network identifier reported for the pool.
